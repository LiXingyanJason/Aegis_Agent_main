# 3.1 固定语料、查询与离线基线

日期：2026-11-02。状态：离线准备与切块基线已完成；真实 Hybrid 召回与答案基线尚未执行，3.1 尚未完整验收。

## 交付

- 数据声明：`tests/evaluation/data/chunking_phase2_v1.json`。
- 冻结、标注及运行脚本：`scripts/evaluate_chunking_baseline.py`。
- 结果：`实验数据/20261102-chunking-baseline-v1.json`，含展开后的原文、确定性版本、正文哈希、片段、证据范围和逐题代理排名。相对代码路径均从 Worker 根目录起算。
- 测试：`tests/evaluation/test_chunking_baseline.py`，4项通过。首次沙箱运行因临时目录权限造成1项setup错误，获准沙箱外重跑后4项全部通过，无数据库或网络访问。

这是新建构造数据，不复用 E04 的旧 chunk 标签。8份虚构文档涵盖制度、合同、项目说明、会议纪要，包含长段落、嵌套标题、编号、列表、Markdown表格、条件／例外分离、章节引用、中英文和邮箱／编号。重复执行说明用于构造长度，不代表真实企业文档分布。

开发集3份文档、6题（可答5、无答案1），测试集5份文档、11题（可答10、无答案1）。跨文档测试题仅引用测试文档。两集只检索各自的文档池，未设训练集，后续不得用测试结果调参。不同切法通过原文证据匹配，不以 chunk ID 作为标签。

标签由实验编写者构造，尚无独立人工盲审；角色包括 rule、condition、exception、cross_reference。展开原文后将唯一证据原句解析为文档版本和 Python Unicode 字符半开区间 `[start,end)`，不是UTF-8字节。脚本校验原句唯一、切片一致及集间隔离，拒绝模糊标注。必要证据列表不是完整参考答案；答案事实正确性仍需逐例评审。

## 冻结配置与测量

数据声明 SHA-256：`112eca83252781ef764a87593b769090ba5fbe6a7bbb04fa5892906e2ef2c852`。结果另存脚本／切块器哈希，语料原文和版本均可追溯。

直接调用生产 `chunk_text`：`paragraph-v1`，size=700、overlap=80、maximum=512；查询改写关闭，无随机算法。离线检索仅按生产 `search_tokens` 的词项集合交集数降序、文档ID及位置打破平局，最多5块、3500字符。它不是 PostgreSQL 全文排名、Embedding、Qdrant 或 RRF，不得与这些真实方法的指标混用。

| 指标 | 实测 |
| --- | ---: |
| 原文字符数 | 8984 |
| 切块数 | 17 |
| 含重叠的片段字符数 | 9704 |
| 本次切块耗时 | 3.327 ms |
| 开发集必要证据范围 | 9 |
| 测试集必要证据范围 | 17 |
| 开发／测试代理范围覆盖率 | 均为100% |
| 开发／测试代理全证据题覆盖率 | 均为100% |

范围覆盖允许同文档多个块的连续区间联合覆盖；另存每个证据是否被单块完整包含的诊断。无答案题不计入可答覆盖分母，保留排名但不把返回候选视为成功回答或幻觉。每题 answer=null、answer_status=not_executed、provider_usage=null；未调用供应商，不将未知Token记为0。external_calls=0只表示本脚本没有外部调用。

这些结果只能证明夹具和离线链路可复跑。文档短、片段少、重复背景多且问题直接，top5容易覆盖整个目标文档，存在明显天花板效应；不能作为切块优化提升或真实检索准确率。后续在开发阶段扩展更长、更接近的干扰资料和独立标注，另发数据版本，保留v1，不事后覆盖已有结果。

## 复跑

在 Worker 目录执行：

```powershell
python -m pytest -q -p no:cacheprovider tests/evaluation/test_chunking_baseline.py
python scripts/evaluate_chunking_baseline.py --output evaluation-results/chunking-baseline-new.json
```

输出采用排他创建，已有文件拒绝覆盖；指定新结果路径。耗时随机器变化，原文、块和排名应一致。脚本不读取.env、用户数据、业务库或现有向量集合，不修改生产切块与检索实现。

## 真实基线的剩余验收

1. 对语料与证据进行独立复核，扩大开发集后另冻结正式数据；最终测试不用于选参。
2. 经单独授权后，冻结实际 Embedding 的供应商／模型／版本／维度、回答模型、实际召回及RRF参数、超时／预算、允许改写和供应商支持的随机设置。当前结果只记录生产参数参考，不把未指定的模型配置伪装成冻结完成。
3. 使用隔离SQL schema／Qdrant集合及治理预算，对真实 Hybrid 保存逐题两路排名、RRF和交付证据、耗时及供应商usage；不得将本次词项代理替代此项。真实安全边界也未由本次离线测试验证。
4. 独立端到端回答实验保存虚构任务答案、引用及人工评分，核对条件、例外、跨章节及无证据拒答，包含费用和失败；不将检索命中等同于答案正确。
5. 留存结果后按授权范围清理隔离资源，补充最终基线报告。未完成前不把3.1整体标记完成，也不以E04指标代替本次实测。
