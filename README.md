# Aegis PA（个人效率 Agent）设计文档集

本项目定位为**隐私优先的个人效率助理**：帮助用户管理日程、分拣和起草邮件、查询信息，以及在受控沙箱中执行代码。它不是无边界自动化机器人；所有会改变外部状态的操作（创建/修改日程、发送邮件、执行代码）都需通过策略校验，并默认要求用户确认。

该方向适合生产化的原因：任务边界清晰、价值可量化、工具权限可最小化，并能充分体现多模型路由、长期记忆、安全治理和可观测性。

## 关键约束

- LLM 只负责理解、规划和生成；最终的权限判断、参数校验和副作用执行由确定性服务完成。
- 邮件发送、日历写入、代码执行均采用“预览 → 确认 → 执行”流程；只读查询可在授权范围内直接执行。
- Redis 仅存会话状态和短期上下文；长期记忆、实体资料、审计事件落 PostgreSQL；语义检索使用 pgvector。
