# 续约回复草稿

根据本轮明确要求和已核验邮件事实组织回复：
1. 简短回应对方的续约事项；没有用户明确意向时，不替用户确认续约。
2. 列出已经确认的条款与需要继续核对的事项，避免遗漏用户提出的问题。
3. 以具体的下一步结束；日期、金额和承诺必须有来源，缺失时用待确认表述。

可参考“回应事项—已知条件／待确认问题—下一步”的三段结构。
用户要求不同结构或语气时，优先遵循用户要求；修改草稿时保留已有事实。
不要把合同到期日当作会议时间，不把邮件签名中的地址自动加入收件人。
本指南不包含公司制度，不证明事实，不授权发送邮件或写入日历。
